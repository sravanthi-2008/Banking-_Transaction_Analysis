# Banking Transaction Analysis | Excel Data Analytics Portfolio Project

## Project Overview

This project analyzes banking transaction data from 2015 to 2022 using Microsoft Excel and Power Query. The goal was to clean transaction data, identify patterns in incoming and outgoing transactions, understand category-level trends, and present key findings through an interactive Excel dashboard.

## Business Objectives

- Assess incoming and outgoing transaction patterns.
- Identify categories contributing the highest outgoing transaction values.
- Analyze transaction frequency across categories.
- Compare average transaction amounts by category.
- Identify monthly transaction trends.
- Build a dashboard to communicate key findings.

## Tools and Technologies

- Microsoft Excel
- Power Query
- PivotTables and PivotCharts
- Excel formulas
- Data visualization and dashboard development

## Data Preparation

Used Power Query to prepare the transaction dataset by:

- Trimming and cleaning text fields.
- Creating a Transaction Direction column to classify incoming and outgoing transactions.
- Correcting transaction dates.
- Applying appropriate data types to columns.

## Key Analyses

1. Incoming vs. Outgoing Transactions – Compared total values, transaction counts, and averages.
2. Category Analysis – Examined outgoing transaction values by category.
3. Monthly Trends – Compared incoming and outgoing transaction values by month.
4. Transaction Frequency – Identified the five most frequent transaction categories.
5. Average Transaction Amount – Identified categories with the highest average outgoing transaction amounts.
6. Category Contribution– Measured the contribution of the top five categories to total outgoing transaction value.

## Key Findings

- Total transaction value: $1,014,382.21
- Total incoming value: $503,203.29
- Total outgoing value: $511,178.92
- Total transactions analyzed: 6,567
- Outgoing transaction value exceeded incoming transaction value by $7,975.63.
- The top five outgoing categories contributed 66.49% of total outgoing transaction value.
- March 2020 recorded the highest incoming monthly value, while June 2020 recorded the highest outgoing monthly value.

## Limitations

Transaction flows alone do not establish account balances, profitability, savings performance, or financial loss. Opening and closing account balances were not included in this analysis.

## Conclusion

This project provided practical experience in data cleaning, exploratory data analysis, PivotTables, Excel formulas, and dashboard development. It demonstrates how raw transaction data can be transformed into structured analysis and meaningful business insights.
